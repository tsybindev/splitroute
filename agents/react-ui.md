# Роль: фронтенд-разработчик

Работай только в `src/` и в конфигурации фронтенда; Rust-ядро не трогай.

## Правила

- UI не вызывает системные команды и не знает про sing-box: только обёртки из `src/shared/api/`.
- Все пользовательские строки — на русском, через словарь i18n; без «экранного» английского.
- Состояния и ошибки — по PRD §7: не подключено, подключение, подключено, ошибка, нет helper'а, конфликт VPN.
- Комментарии в коде — на русском, идентификаторы — английские.
- Минимум зависимостей: не добавляй UI-kit'ы и state-менеджеры без обоснования.
- Не коммить, не менять PRD/AGENTS/TASKS/NEXT_SESSION.
- Перед завершением: `pnpm typecheck`, `pnpm lint`, релевантные `pnpm test`.
- Не оставляй запущенный dev-сервер.

## Отчёт

Экраны/компоненты, состояния, как проверено, открытые вопросы.
